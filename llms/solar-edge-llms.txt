# SolarEdge Monitoring API

> Read-only REST API over the SolarEdge photovoltaic monitoring platform. Returns site
> inventory, energy and power production, battery/storage telemetry, environmental
> benefits, equipment/inverter data, meters and sensors for sites the calling account can
> access. Authentication is a single api_key query parameter issued in the SolarEdge
> monitoring platform. Responses are JSON by default. Errors use RFC 9457 problem+json.
> Generated by the API Evangelist enrichment pipeline (2026-07-21) from public docs and a
> live host probe; not an official SolarEdge document.

## API
- [SolarEdge Monitoring API base](https://monitoringapi.solaredge.com): production host (api_key required; live probe returns RFC 9457 401 without a valid key).

## Endpoints
- GET /sites/list — Site List
- GET /site/{siteId}/details — Site Details
- GET /site/{siteId}/dataPeriod — Site production start/end dates
- GET /site/{siteId}/energy — Site Energy
- GET /site/{siteId}/timeFrameEnergy — Site Energy for a period
- GET /site/{siteId}/power — Site Power (15-min)
- GET /site/{siteId}/overview — Site Overview
- GET /site/{siteId}/powerDetails — Site Power (detailed, meters)
- GET /site/{siteId}/energyDetails — Site Energy (detailed, meters)
- GET /site/{siteId}/currentPowerFlow — Current power flow (PV/load/grid/storage)
- GET /site/{siteId}/storageData — Battery/storage telemetry
- GET /site/{siteId}/envBenefits — Environmental benefits
- GET /site/{siteId}/inventory — Site equipment inventory
- GET /equipment/{siteId}/list — Components list
- GET /equipment/{siteId}/{serialNumber}/data — Inverter technical data
- GET /equipment/{siteId}/{serialNumber}/changeLog — Equipment change log
- GET /site/{siteId}/meters — Site meters
- GET /equipment/{siteId}/sensors — Sensor list
- GET /site/{siteId}/sensors — Sensor data
- GET /accounts/list — Accounts list
- GET /version/current — Current API version
- GET /version/supported — Supported API versions
